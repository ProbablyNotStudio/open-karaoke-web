Adding a folder

Some browsers and phone file pickers only let you choose files. If a folder cannot be selected, extract your ZIP, open the extracted folder in the file picker, and select its songs together. You can repeat this for subfolders.

For a whole folder including subfolders, use a supported desktop browser such as Chrome or Edge.

Import results

Successfully added songs are ready in your library. Only retry the files below. For a failed file inside a ZIP, extract it and add it again, or replace it with a complete copy.

    Make it yours

    Using the built-in synth.

    iPhone and iPad start with the lightweight built-in synth. Your saved instrument choice is respected. For lower memory use, choose Use lightweight synth. A selected SoundFont downloads once and is saved in this browser for reuse. SoundFonts change MIDI instruments. Add one or more .sf2 files, up to 1 GB (1,024 MB) each. Large fonts can require several GB of memory and may fail on phones or low-memory devices. Personal fonts stay on your device and reload in this browser. Drums-only fonts may leave other instruments silent.

    Background videos

    Folders are detected automatically. If your phone hides subfolder names, add Nature, 3D or Motion separately and enter its collection name here.

    Restoring your backgrounds…

    Choose your own MP4 or WebM videos. Use Add video folder and select the top folder (such as bgv); videos inside all subfolders are included. Videos loop silently behind MIDI and audio songs. Random mode picks a different video for each song when possible. Backgrounds stay on this device and reload in this browser. Karaoke videos and CDG use their own visuals.

    Restoring your saved library…

    Songs and SoundFonts reload in this browser. Storage depends on available space; private browsing or clearing browser data can remove them. Clear songs removes the saved song library, queue and favorites. Clear SoundFonts removes saved instruments and switches to the built-in synth. Background videos are cleared separately above.     Your quick guide

    1. Add your own songs. Use Add songs for individual files or ZIP archives, or Add a folder. Personal imports stay on your device and reload in this browser.
    2. Import a ZIP. Song files in folders are extracted locally; matching audio, CDG and LRC files pair within the same folder. Nested ZIPs, encrypted archives and unsupported formats are excluded. Limit: 128 MB ZIP, 256 MB extracted songs, 64 MB per archived file, 2,000 archive entries. Import larger media individually.
    3. Pair CDG files. Import both Title.mp3 and Title.cdg with the same filename stem, in the same folder.
    4. Play MIDI karaoke. Standard format 0/1 .mid, .midi, and .kar files play with embedded timed lyric/text events. Key controls apply to MIDI.
    5. Reserve songs. Tap + to queue, ↑ or ↓ to reorder, or × to remove. The same song can be queued more than once. Your queue restores in this browser after a refresh.
    6. Use LRC lyrics. Import an audio file with a matching .lrc for timed lines.

    Use Space to pause, F1 to search, F9 for settings, and F11 for fullscreen.

    Your favorites and settings stay in this browser.
