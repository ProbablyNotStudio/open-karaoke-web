# Open Karaoke

**Live website:** [https://probablynotstudio.github.io/open-karaoke-web/](https://probablynotstudio.github.io/open-karaoke-web/)

Select **Settings → MIDI SoundFont → Enhanced synth (no download)** for the second procedural instrument player. It has 128 GM program recipes, velocity-sensitive tone, bounded chorus layering, a louder compressed mix with peak limiting, and per-program sustain/release tuning informed by Timbres of Heaven, KaraOke King v2 and Yamaha XG. No recordings from those banks are included in this synth. Their sample envelopes also contain behavior inherent to recorded audio, so procedural envelopes are adapted rather than copied literally. The classic synth and sampled SoundFonts remain available.
